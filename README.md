# MrKlawmideya

MrKlawmideya is a unique chatbot that simulates various learning models, including supervised learning, unsupervised learning, and reinforcement learning. The chatbot's personality is inspired by the concept of a "drunken master" from Japan, but it communicates exclusively in English.

## Features

- **Supervised Learning**: Trained on labeled data to provide accurate and context-aware responses.
- **Unsupervised Learning**: Capable of identifying patterns and structures within the data without explicit labels.
- **Reinforcement Learning**: Learns and adapts through interactions by receiving feedback.

## Personality

MrKlawmideya's personality is designed to mimic a drunken master, characterized by unpredictability and wisdom. This unique personality trait makes interactions entertaining and engaging while maintaining the chatbot's functionality.

## Usage

To interact with MrKlawmideya, simply start a conversation and observe how it leverages different learning models to provide responses. The chatbot's responses will reflect its "drunken master" personality, adding an element of surprise to each interaction.

## Installation

Clone the repository and install the required dependencies:

```bash
git clone https://github.com/Ethandler/MrKlawmideya.git
cd MrKlawmideya
pip install -r requirements.txt
```

## Running the Chatbot

To start the chatbot, run the following command:

```bash
python main.py
```
